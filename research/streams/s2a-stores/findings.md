## (а) TL;DR

1. **Главный сигнал — лимиты и расход AI-ассистентов.** Категория горячая сразу в четырёх сторах:
   - CWS: лидер Claude Usage Tracker — 100k, 4.77★.
   - VS Code: Claude Code Usage — 75.5k, плюс 60.9k на Open VSX.
   - Raycast: ccusage — 14.7k.
   - AMO: Claude Usage Tracker — 4.9k ADU.

   Мульти-провайдерные и мульти-агентные решения пока слабые: в VS Code у таких меньше 600 установок. Новички добирают 10k за 2–6 месяцев. Пример: Conso — 10k примерно за 2 месяца (≈4.9k/мес, estimate).
2. **Paper trading для memecoin-терминалов — второй по силе сигнал в нашей крипто-нише.**
   - DryFlip: 40k, 4.51★, ≈4.5k/мес с 2026-02. MockApe: 20k.
   - Hyperliquid/perps не покрыты: в поиске CWS по «hyperliquid» paper-trading расширений нет.
   - В Firefox один игрок (748 ADU).
   - Модель read-only, без ключей, поэтому проходит G4.
   - Предупреждение о выжившем: медиана из 15 найденных paper-расширений — 75 users.
3. **В Telegram выигрывает read-only аналитика подарков (Gifts):**
   - рынки: MRKT — 486,883 MAU, Portals — 385,286 MAU;
   - оценщики: NFT GIFT Calculator — 82,669 MAU, Gift Charts — 11,926 MAU.

   Деньги идут через Stars → Fragment → TON. Это единственный найденный путь к крипто-выручке без юрлица прямо из стора, но вывод требует KYC.
4. **Сироты массовых dev-утилит в CWS** (трафик есть, а лидер заброшен или испорчен):
   - Cookie-Editor: 2M, не обновлялся с 2024-02;
   - JSON Formatter: 2M, 1.51★ после продажи и рекламы;
   - SelectorGadget: 100k, не обновлялся с 2022-08;
   - TickerIQ: 400k, с 2025-01;
   - Wallet Guard: 60k, с 2025-05;
   - Ethereum Gas Price Extension: 40k, с 2025-03.

   Но перехватчики уже растут, а новички в старых категориях набирают 300–600 users/мес. До 10k — больше года.
5. **В библиотеке n8n по крипто-запросам почти пусто:** rpc — 0 шаблонов, whale — 2, dexscreener — 2, ethereum — 4 (все с 0 просмотров). При этом лучшие крипто-шаблоны набирают 11.9k–13.1k просмотров. Дёшево, и аудитория — покупатели автоматизации: лучшая синергия.
6. **VS Code и Open VSX:**
   - лидеры REST-клиентов испорчены: Thunder Client — 7.68M, 2.36★ (paywall); REST Client — 7.7M, без обновлений с 2022-08;
   - на Open VSX нет 59 из 304 проверенных топ-расширений VSM;
   - но порт сам по себе трафика не даёт: форки quicktype на OVSX — 1.7k и 1.2k загрузок.
7. **Shopify и Raycast для нас слабые.**
   - Shopify: адрес разработчика публичный, деньги только через Billing API; Payoneer через Hyperwallet не подтверждён. Мессенджер- и uptime-приложения — 0–12 отзывов, то есть спрос не доказан.
   - Raycast: монетизации в сторе нет; 10k+ набрали только 6.5% расширений. Крипто-раздел почти пустой: лидер 5.7k за 5 лет.
8. **Make закрыт для нас:** шаблоны курирует Make, открытой creator-программы для физлиц не нашли; сайт за Cloudflare, метрик нет.
9. **Общий вывод для G2:**
   - CWS, AMO, VS Code, Open VSX и n8n позволяют физлицу публиковаться без раскрытия адреса (CWS — статус non-trader) и брать крипту за внешний премиум;
   - Shopify требует публичный адрес и фиатный биллинг;
   - Telegram — Stars, а крипто-функции в Mini App только на TON.

## Платформы

### 1. Chrome Web Store (+ Firefox AMO; Edge не собран)

**Механика трафика**
- Поиск выдаёт около 10 карточек на запрос, затем «Load more».
- Совпадение запроса с названием сильно влияет на видимость:
  - новые расширения с exact-match названием попадают в топ рядом с лидерами (Conso, ClaudeKarma, Claude Usage Meter — все 2026 года, у всех 10k+);
  - бренды без ключевого слова в названии теряют видимость: Wappalyzer не появился по «tech stack detector».
- Публичные метрики: users (округлённо), рейтинг, число оценок, дата обновления, статус Trader/Non-trader.
- Все просмотренные карточки на MV3.
- В AMO публичны average daily users (ADU), рейтинг и last_updated. Аудитория в 10–20 раз меньше CWS, конкуренция почти нулевая.

**Условия для физлица и крипты**
- Вход $5 один раз (fact, developer.chrome.com).
- Каждый разработчик объявляет статус trader или non-trader по EU DSA. Non-trader не раскрывает адрес и телефон; многие крипто-расширения публикуются как Non-trader, например Solflare.
- Встроенного биллинга нет: CWS Payments закрыт. Премиум делается через свою лицензию и свой чекаут, поэтому крипта (USDT/USDC) за внешний премиум возможна. Явного запрета в правилах не нашли, но формально это нужно проверить в Program Policies (claim).
- Payoneer к платформе не относится: платформа сама ничего не выплачивает.
- AMO: бесплатно, физлицо, ссылка на донаты в карточке.

### 3. Raycast Store

**Механика трафика**
- Поиск и витрина внутри приложения Raycast (macOS, есть Windows-бета). Каталог через API: 3,487 расширений, 14.87M загрузок суммарно.

**Условия**

- Монетизации в сторе нет. Можно продавать только внешний API или премиум, но формально это не прописано: crypto_payment_ok = «?».

**Лучшие дыры**

Вывод: Raycast годится только как бесплатный спутник основного продукта.

### 4. Shopify App Store

**Механика трафика**
- Поиск плюс категории плюс бейдж «Built for Shopify». Ранжирование заметно зависит от числа отзывов.
- Установки не публичны, поэтому прокси — число отзывов.
- Рейтинги завышены (почти у всех 4.8–5.0), сигнал низкого рейтинга слабый.

**Условия**
- Регистрация $19 один раз.
- Партнёр может быть физлицом.
- Деньги только через Shopify Billing API: 0% комиссии до $1M за всё время, затем 15%.
- Выплаты через Hyperwallet (минимум $25). Payoneer напрямую не подтверждён: только форумные обсуждения, нужна проверка для страны KYC.
- В листинге публикуется адрес разработчика (пример: «Bajorų k., Vilniaus raj., LT»), поэтому `public_address_required = y`.
- Крипто-платежи для мерчантов — это payment providers с договором, а не приложения (G2).

**Дыры** (все с недоказанным спросом)
- Telegram-уведомления: Dingio запущен 2026-08-07, 0 отзывов; EasyGo13 — 2; DI TeleNotify — 1; TelePing — 3, 4.1★. Сама задача low-stock алертов востребована: iAlert 98 отзывов, Bee 129, Stockbot 41. Telegram как канал — не доказан.
- Uptime / QA магазина: Playecom Watch 1, Blimey 1, Shoptest 5 — пусто.
- Discord: Discord Connect 12 отзывов.
- Webhooks: закрыто нативным Shopify Flow; Workflow Webhooks — 7 отзывов.

Вывод: для нас Shopify — низкий приоритет (constraints 2/5).

Итог: Stars → TON — рабочий путь к крипто-деньгам без юрлица, но с KYC и холдом.

## (б) Закономерности

1. **Новые категории дают новичкам скорость, старые — нет.**
   - В категориях 2025–2026 (AI usage, paper trading) новички набирают 1.8–4.9k users в месяц: Conso, DryFlip, ClaudeKarma.
   - В категориях 2015–2020 (selector, JSON, gas, page monitor) свежие расширения растут на 12–650 users/мес даже при заброшенных лидерах. Пример: PagePulse — 113 users за 7 месяцев.
   - Вывод: заброшенный лидер не равен свободному трафику. Стор ранжирует по users, рейтингу и возрасту.
2. **Отбор выживших силён.**
   - AI usage: из 35 найденных расширений ≥10k набрали 4, медиана — 441 users.
   - Paper trading: из 15 ≥10k набрали 2, медиана — 75 users.
   - Скорость аналогов в `time_to_10k` — это скорость победителей. Для медианного новичка срок ×3–10.
3. **Exact-match название решает в CWS.** Расширения с названием, совпадающим с запросом, попадают в топ рядом с лидерами. Значит, нужен портфель из узких названий под конкретные запросы, а не один бренд.
4. **Одна потребность сразу в нескольких сторах.** AI usage горяч одновременно в CWS, VSM, OVSX, Raycast и AMO. Одно ядро — 4–5 листингов, а Firefox и Open VSX почти пусты.
5. **Продажа или paywall лидера открывает окно.** JSON Formatter (продажа и реклама → 1.51★) и Thunder Client (paywall → 2.36★) сохранили миллионы пользователей. Но окно быстро занимают форки, поэтому нужна скорость.
6. **Крипто-спрос в сторах узкий и трейдерский.** Сильный спрос — у paper trading, Telegram Gifts и безопасности кошельков. Оверлеи DexScreener, rug-чекеры, аирдропы, газ-трекеры для BTC — ≤1k users. Крипто-аудитория живёт в терминалах и Telegram, а не в браузерных утилитах.
7. **Монетизация.**
   - Крипта без юрлица проще всего:
     - CWS, AMO, VSM и OVSX: свой чекаут для премиума;
     - Telegram: Stars → TON;

## (г) Что не удалось проверить и почему

- **Edge Add-ons** не собраны: не хватило времени, в приоритете были CWS и AMO. Считаем Edge дешёвым дублем CWS-листинга.
- **Make templates:** сайт за Cloudflare-челленджем, обходить нельзя. Метрик шаблонов нет; открытой creator-программы для физлиц не нашли.
- **Shopify:** установки не публичны (используем отзывы как прокси). Выплата через Hyperwallet на Payoneer не подтверждена — только форумные обсуждения. Охват 16 запросов.
- **Raycast:** правила внешней монетизации (платный API за расширением) явно не описаны.
- **Дата создания в CWS** взята из поля во встроенных данных страницы, а не из официального API, поэтому все «users/мес» — estimate. Цифра users в CWS округлена.
- **TickerIQ 400k** при 34 оценках — возможна пред-установка или бандл. Цифра не проверена.
- **Telegram ToS:** неясно, подпадает ли read-only аналитика Solana/EVM в обычном боте (не Mini App) под раздел 7 «crypto functionality». Нужна юридическая сверка. Требования KYC Fragment на 2026 год подтверждены только источником 2025-08.
- **Open VSX gap-скан:** проверено 304 из 400 запланированных расширений. Статус «не найдено» может включать таймауты API.
- **Правила n8n:** условия продажи платных шаблонов (допустимые purchaseUrl, комиссия) официально не найдены. Есть только форумный отзыв (claim).
- **Отзывы за логином** и детальные графики установок (CWS Developer Dashboard, VSM Reports) — за логином, не смотрели.
