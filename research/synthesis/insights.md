# Кросс-потоковые инсайты фазы 1

Дата: 2026-11-02. Здесь только то, что видно при сведении потоков. Внутрипотоковые выводы — в итогах потоков. Ссылки C-NNN ведут в [`candidates_master.csv`](candidates_master.csv).

## 1. Лимиты и статусы AI-моделей — самый доказанный спрос, но не наши деньги
**Сходимость.**
- **S2a — спрос в сторах:** Claude Code Usage 75.5k + 60.9k установок, Claude Usage Tracker 100k; новички 1.8–4.9k/мес.
- **S4 — боль:** самый громкий кластер — 18 сигналов, 100% явный WTP, ~255k просмотров; Ask HN о падении OpenAI/Claude — 404 пойнта.
- **S2b — витрины:** цены и статус LLM в ChatGPT пусты (0–1 листинг); каталог Claude разрешает LLM-данные, хотя крипту запрещает.
- **S1 и S5 — пределы:** price-борды LLM насыщены, окно 2025 закрыто.
- **S6:** сезонные «AI coding wrapped» не взлетели — около 10 клонов, 14 загрузок в месяц.

**Вывод.** Открыты две двери:
- usage-метр в сторах — C-012, №1, 70.5;
- «is X down» по моделям с реальной латентностью — C-009, 58.5, три потока.

Price-бордов и wrapped в списке нет. Монетизация у обоих 2/5: аудитория платит картой. Это двигатель трафика для мониторинга AI-API и услуг, а не крипто-выручка.

## 2. Заброшенный лидер ≠ свободный трафик: в старых категориях покупать, в новых — строить
**Сходимость.**
- **S2a — старые категории:** новички в категориях 2015–2020 (газ, selector, JSON, мониторинг страниц) набирают 12–650 users/мес даже при заброшенных лидерах.
- **S2a — новые категории:** в категориях 2025–2026 — 1.8–4.9k/мес.
- **S7 — цена покупки:** аудиторию старше ~3 лет выгодно покупать — buy_premium в 15–80 раз больше build_cost, но построить её всё равно не выйдет.
- **S1:** у расширений нет подтверждённых быстрых кейсов (медиана VS Code — 804 установки).

**Вывод — правило «build vs buy»:**
- категория моложе ~2 лет → строим: C-012, C-014;
- категория старше ~3 лет → только покупка: C-021, C-022, C-023;
- свой клон в старой категории не делаем.

Поэтому C-021 и C-022 в топ-15, хотя confidence L. Их судьба зависит от цены и решения команды о контакте.

## 3. Лучшая петля — «шер, который видят все»; карточки в X без посева не работают
**Сходимость.**
- **S1:** групповые TG-боты — самый сильный встроенный механизм. Админ ставит бота один раз, карточки видят все: Rose 2.32M MAU, Rick 58.5k.
- **S6 — бенчмарк шеров:**
  - share rate ≈2.5% даже у GitHub Unwrapped;
  - ≥10% реально только там, где шер виден автоматически: пост в канале, групповой чат, бейдж в README;
  - десятки wrapped-клонов без посева получили около нуля.
- **S2a:** карточки «мой профиль стоит N TON» расходятся по gift-чатам.
- **S2b:** Farcaster mini apps без ежедневного постинга не растут (медиана 287 WAU).

**Вывод.** Из UGC-кандидатов выше ставим те, где выход автоматически виден группе: C-001 (групповой бот), C-050 (пост в канале). Для карточек «шер в X» (C-048, C-049) закладываем посев заготовленными карточками известных кошельков и архетипы для проигравших.

## 4. Крипто-деньги платит B2B-сторона, а не пользователь
**Сходимость.**
- **S1 — трафик ≠ деньги:**
  - рассылка на 85k подписчиков → $122;
  - DappRadar закрылся при 500k пользователей;
  - при этом DEX Screener получает $3.28M за 30 дней от команд токенов, Revoke.cash — ~150k OP грантами.
- **S2b — запреты платформ:** в плагине ChatGPT продавать нельзя, каталог Claude крипту запрещает.
- **S2a:** единственный путь к крипте прямо из стора — Stars → Fragment → TON, с KYC.
- **S7:** крипто-контент продаётся за 0.1–2× прибыли; эскроу-площадки крипту не принимают.

**Вывод.** Для крипто-монетизации выше ставим кандидатов, где платит команда или протокол:
- C-001 — спонсорские слоты оплачивают команды токенов;
- C-043 — протоколы платят за мониторинг DNS;
- C-005 — спонсорство проектов на TGE.

Плагины ChatGPT (C-003, C-005, C-035) — только воронка на свой сайт или бота.

## 5. Один бэкенд чекера — пять витрин; в зачёт идут только те, где есть discovery
**Сходимость.** Один бэкенд чекера потоки предлагают выставить на разных витринах:
- S1: групповой TG-бот, веб-страницы с бейджами, MCP;
- S2b: ChatGPT, Seeker, x402, реестры;
- S2a: anti-phishing в Chrome.

Но витрины без discovery внутри клиента трафика не дают:
- S1: Apify $157, RapidAPI $20 в месяц;
- S2b: официальный реестр — 54,941 сервер без метрик, x402 Bazaar — 77% листингов с ≤2 плательщиками.

**Вывод.** Делаем один MCP-сервер, но ставку делаем только на витрины с discovery:
- каталог ChatGPT с подсказками в чате — C-003;
- Solana dApp Store со стимулами Seeker Season — C-004;
- групповой бот — C-001.

Реестры — гигиена на 1 день, а не канал. Отдельный MCP в реестрах и generic price-MCP в мастере понижены или отсеяны (C-003 включает S1-015 и S2b-010; C-074 — G1).

## 6. SEO в этом цикле структурно проигрывает
**Сходимость.**
- **S1:** форматы engineering-as-marketing забиты AI-клонами: «is Solana down» отдают 8+ сайтов, EVM dev-утилит 6+ наборов, RPC-бенчмарков 6+.
- **S5:** 26 из 34 data-ниш насыщены клонами с одинаковым набором (CC BY, CSV, MCP, DOI); новая ниша насыщается за месяцы.
- **S4:** окно «X alternative» после закрытий длится 2–8 недель, и его забирают вендоры.
- **scoring.md:** SEO не даёт честного сигнала раньше 8-й недели.

**Вывод.**
- В топ-15 нет ни одного чисто SEO-кандидата: на новом домене SEO даёт 10k только за 4–6 мес.
- SEO оставляем вторым слоем на домене чекера, и только для событийных интентов: TGE (C-005), падения (C-009, C-010), хаки (C-007, C-043).
- Чистые SEO-кластеры (C-060 dev-утилиты, C-011 RPC-борд) — в хвосте рейтинга.

**Сходимость.** Почти все быстрые старты в данных — событийные:
- **S1:** окно новой сети (Proficy: 183k из 568k сканов на Robinhood Chain), TGE (Drops), гео-разрывы;
- **S4:** закрытия сервисов и подорожания (Zapper, Freshping, Etherscan free-tier);

Мониторинг — наша сильная сторона. Он кормит C-001, C-005, C-007, C-010, C-020, C-041 и C-043 и превращает «окна» из удачи в процесс.

## 8. Hyperliquid и TON — недообслуженные экосистемы, но спрос живёт в разных местах
**Hyperliquid.** Сходимость:

- S2b: 68 HL-серверов в реестре — интерес билдеров;
- S4: ни одного HL-сигнала (Reddit недоступен).

Один слой данных HL на публичном Info API обслуживает сразу C-048, C-014 и C-037.

**TON.** Спрос живёт внутри Telegram:
- S2a: подарки — ~930k MAU у рынков;
- S6: TON Year — риск, что self-custody пользователей мало;
- S2b: в ChatGPT TON-плагинов 0, но и спроса там не видно;
- S2a: Raycast TON Address — 27 загрузок.

Правило: TON-продукты делаем только внутри Telegram (C-016, C-001 на RU/TON). В ChatGPT TON — одна сеть внутри C-003, не отдельный плагин.

## 9. Конфликт по времени: ноябрь–декабрь перегружен
**Сходимость.** На одно окно приходятся сразу три дедлайна:
- **S6:** сезонные карточки нужно выпустить до ~7 декабря;
- **S2b:** подать плагин ChatGPT лучше до 2026-12-11, пока каталог не забили переехавшие GPT;
- **S1:** окно новой сети — по календарю мейннетов.

При этом в профиле ⚠ всего ~20 человеко-часов в неделю на новые активы — около 90 часов с 11-03 по 12-04. Этого хватает только на один MVP до декабря: либо C-048 (около 80 часов, сезон сгорает 31 декабря), либо C-003 (7–8 дней, окно до 2026-12-11). Оба сразу — только если команда добавит часы. Остальное — после S3.
