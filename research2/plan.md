## 3. Правила исполнения (применяются ко всем осям)

Переносятся из блока «ПРАВИЛА ДОСТОВЕРНОСТИ» без изменений + эксплуатационные уточнения:

- Каждое число — с URL-источником **либо** пометкой `[ОЦЕНКА]` + обоснование в одну строку. Выдумывать числа запрещено.
- Нет данных → писать «**нет данных**» (нормальный результат).
- Каждый API/фид/сайт по возможности проверять вживую (открыть фид, `robots.txt`, документацию) и ставить **дату проверки**.
- Маркетинговые цифры продавцов (cold-email тулы, агентства) → пометка «**источник заинтересован**».
- Всё, что старше 2025 → пометка «**устарело (до 2025)**». Текущая дата прогона — октябрь 2026.
- Бюджет: приоритет бесплатным решениям; платное не исключать, но помечать ценой и выносить отдельно.
- **Этико-правовая рамка для оси 3:** только **пассивные, публично наблюдаемые** признаки (какой билдер, видимые в публичном ответе заголовки/мета, публичные security-заголовки). **Никакого** активного сканирования, перебора, эксплуатации, обхода авторизации или нарушения ToS/CFAA. Запреты ToS на скрейпинг/коммерческое использование — фиксировать честно, а не обходить.

## 4. Протокол файлов

- `research2/raw/<N>-<slug>.md` — полный дамп по оси: все источники, живые проверки, цитаты, даты.
- `research2/findings/<N>-<slug>.md` — дистиллят: структурированный ответ «что / откуда / условия / отдача».
