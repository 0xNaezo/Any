# Nightloom — сайт студии

Одностраничный лендинг для команды из четырёх разработчиков: портфолио и приём заказов.
Тёмная тема, редакционно-технический минимализм, логотип-призрак, «сотканный» из нитей.

- **Astro 7**: статический HTML, ноль JS-фреймворков на клиенте.
- **GSAP 3** (ScrollTrigger, SplitText, ScrambleText) и **Lenis** для анимаций и плавного скролла.
- **Canvas 2D**: интерактивный призрак из нитей в первом экране и на странице 404.
- Шрифты Geist, Geist Mono и Instrument Serif лежат в проекте (без Google Fonts).
- Без cookies, трекеров и внешних запросов.

## Быстрый старт

Нужен **Node.js 22.12+**.

```bash
npm install
npm run dev       # http://localhost:4321
npm run build     # сборка в dist/
npm run preview   # локальный просмотр сборки
npm run check     # проверка типов
```

## Где менять тексты

**Весь контент лежит в одном файле: [`src/data/site.ts`](src/data/site.ts).** Компоненты трогать не нужно.

| Блок | Ключ в `site.ts` |
| --- | --- |
| Название, юрлицо, слоган, email, год основания | `name`, `legalName`, `tagline`, `email`, `founded` |
| Title/description для поиска и соцсетей | `meta` |
| Город, часовой пояс, рабочие часы (живые часы и статус «Online now» в первом экране) | `location` |
| Статус загрузки («Booking from…»). `open: false` перекрашивает точку в янтарный | `availability` |
| Telegram, ссылка на созвон, соцсети | `links`, `socials` |
| Первый экран | `hero` |
| Логотипы клиентов, рейтинг, цифры | `clients`, `stats` |
| Кейсы | `work.items` |
| Отзывы | `testimonials` |
| Услуги и стек | `services` |
| Этапы работы | `process` |
| Принципы («We don’t ghost.») | `principles` |
| Команда | `team` |
| Цены | `pricing` |
| FAQ (попадает и в разметку для Google) | `faq` |
| Форма и контакты | `contact` |
| Футер, реквизиты | `footer` |
| Страница 404 | `notFound` |

Разметка внутри текстов:

- `*слово*` — курсив с засечками, например `'Small team.\nSerious *software.*'`;
- `\n` — перенос строки (в заголовках).

Номера секций (`index: '01'`…) заданы вручную. Если удаляете или переставляете секцию, обновите их,
а также `nav` и список секций в [`src/pages/index.astro`](src/pages/index.astro).

## Чек-лист перед запуском

Сейчас **все тексты, имена, цифры и отзывы выдуманы**. Перед публикацией:

- [ ] **Отзывы.** Публикуйте только реальные отзывы и только с согласия автора. Выдуманные отзывы
      вводят клиентов в заблуждение и во многих странах нарушают закон о рекламе.
- [ ] **Логотипы клиентов.** Сейчас это вымышленные бренды. Ставьте логотип только с разрешения клиента.
- [ ] **Цифры:** `stats`, рейтинг (`clients.rating`), метрики в кейсах.
- [ ] **Кейсы:** названия, тексты, стек, картинки (см. ниже). Под NDA можно писать «fintech-стартап» без названия.
- [ ] **Команда:** имена, роли, опыт, города, ссылки, фото.
- [ ] **Контакты:** `email`, `links.telegram`, `links.call` (Cal.com или Calendly), `socials`.
- [ ] **Реквизиты:** `legalName`, `footer.legal`.
- [ ] **Загрузка и часы работы:** `availability`, `location`, `hero.facts`.
- [ ] **Цены и условия:** `pricing`, `faq`.
- [ ] **Форма:** подключить отправку (см. ниже) и отправить тестовую заявку.
- [ ] **Домен:** задать `SITE_URL` при сборке (см. «Деплой»).
- [ ] **OG-картинка:** обновить `public/og.png`, если поменялся заголовок.

## Картинки

Все файлы кладутся в `public/`, а в `site.ts` пишется путь от корня сайта.

**Кейсы.** Сейчас вместо скриншотов нарисованные SVG-интерфейсы (`visual: 'ledger' | 'freight' | 'store' | 'docs'`).
Чтобы поставить настоящий скриншот:

```ts
{ client: 'Ledgerly', image: '/work/ledgerly.webp', ... }   // файл: public/work/ledgerly.webp
```

Формат 4:3, лучше 1600×1200, WebP или AVIF. Поле `href` добавит ссылку на продукт или полный кейс.

**Команда.** `photo: '/team/mark.webp'`: портрет 4:5 (например, 800×1000). На сайте фото
выводятся в чёрно-белом, в общем стиле сайта. Пока фото нет, выводится «сотканный» силуэт.

**Логотипы клиентов.** `logo: '/clients/ledgerly.svg'` у нужного элемента в `clients.logos`. Лучше
одноцветный SVG на прозрачном фоне: на сайте любой логотип приводится к приглушённому серому, чтобы
полоса логотипов выглядела ровно. Без `logo` выводится текстовый вордмарк.

**Иконки и превью для соцсетей:**

- `public/favicon.svg`: основной фавикон, сам подстраивается под светлую и тёмную тему браузера;
- `public/favicon-32.png`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`: PNG-версии;
- `public/og.png` (1200×630): превью ссылки в Telegram, Slack, LinkedIn и т. п. Исходник лежит
  в [`design/og.html`](design/og.html). Поменяйте текст и пересоберите картинку:

  ```bash
  npx playwright screenshot --viewport-size "1200, 630" --wait-for-timeout 800 design/og.html public/og.png
  ```

Логотип в шапке и футере задан как SVG в [`src/components/GhostMark.astro`](src/components/GhostMark.astro).

## Форма заявки

Настраивается в `contact.form` в `site.ts`. Есть четыре варианта.

1. **Ничего не настраивать.** Пока `endpoint` пустой, при отправке открывается почтовый клиент
   с готовым письмом на `email`. Работает сразу, но часть людей до отправки письма не дойдёт.
2. **[Formspree](https://formspree.io).** Создайте форму и вставьте адрес:
   `endpoint: 'https://formspree.io/f/xxxxxxx'`.
3. **[Web3Forms](https://web3forms.com).** `endpoint: 'https://api.web3forms.com/submit'`,
   `accessKey: 'ваш-ключ'`. Заявки приходят на почту.
4. **Telegram.** Заявки приходят сообщением в личку или в чат команды. Для этого есть готовый Cloudflare Worker:
   [`integrations/telegram-worker.js`](integrations/telegram-worker.js). Пошаговая настройка
   (около 5 минут) описана в комментарии в начале файла. После деплоя вставьте URL воркера в `endpoint`.

Форма отправляет `POST` с JSON:

```json
{
  "name": "…", "email": "…", "company": "…",
  "needs": "New product, Website", "budget": "$20–50k", "plan": "Audit sprint",
  "nda": "Yes", "message": "…", "subject": "New project request — Nightloom"
}
```

Любой ответ с кодом 2xx считается успехом. В форме есть проверка полей, скрытое поле-ловушка для ботов (honeypot)
и подстановка тарифа: кнопки в блоке цен сами отмечают выбранный план. После отправки показывается
сообщение с ближайшим рабочим днём, когда придёт ответ. День считается по часовому поясу и рабочим дням студии.

## Деплой

Сайт полностью статический: после `npm run build` достаточно выложить папку `dist/` на любой хостинг.

При сборке задайте переменные окружения:

| Переменная | Зачем | Пример |
| --- | --- | --- |
| `SITE_URL` | канонические ссылки, sitemap, превью для соцсетей | `https://nightloom.dev` |
| `BASE_PATH` | только если сайт открывается из подпапки | `/nightloom-site` |

- **Vercel, Netlify, Cloudflare Pages.** Build command: `npm run build`, output: `dist`,
  переменная `SITE_URL` задаётся в настройках проекта. Node берётся из `.nvmrc`.
- **GitHub Pages** (адрес вида `username.github.io/repo`):
  `SITE_URL=https://username.github.io BASE_PATH=/repo npm run build`.
- **Свой сервер.** Отдайте `dist/` через nginx или Caddy и настройте `404.html` как страницу ошибки.

`sitemap-index.xml` и `robots.txt` генерируются автоматически.

## Структура

```
src/
  data/site.ts           ← весь контент
  pages/                 index, 404, robots.txt
  layouts/Base.astro     <head>, мета-теги, JSON-LD, шапка и футер
  components/            секции и UI (Hero, Work, Pricing, Contact…)
  scripts/
    main.ts              точка входа: подключает всё остальное
    threads.ts           canvas: призрак из нитей
    animations.ts        анимации при скролле (GSAP)
    header.ts            шапка, мобильное меню, подсветка активного раздела
    scroll.ts            плавный скролл (Lenis) и переходы по якорям
    form.ts              форма заявки
    interactions.ts      «магнитные» кнопки, подсветка карточек, часы, FAQ, копирование email
  styles/global.css      дизайн-токены (цвета, отступы, типографика) и базовые стили
public/                  иконки, OG-картинка, manifest
design/og.html           исходник OG-картинки
integrations/            Cloudflare Worker: форма → Telegram
```

**Цвета и шрифты** настраиваются в `:root` в [`src/styles/global.css`](src/styles/global.css).
Акцентный цвет задают `--accent` и `--accent-rgb`. Шрифты подключаются в [`astro.config.mjs`](astro.config.mjs).

## Что уже учтено

- **Доступность:** контраст текста по WCAG AA (проверено axe), навигация с клавиатуры,
  ссылка «Skip to content», фокус не выходит из открытого мобильного меню, ARIA для формы и FAQ.
- **Reduced motion:** если в системе включено «уменьшить движение», анимации и плавный скролл
  отключаются, а весь контент показывается сразу.
- **Без JavaScript** сайт остаётся полностью читаемым, и форма всё равно работает: отправляется обычным
  POST на `endpoint` или, если он не задан, открывает почтовый клиент.
- **Производительность:** около 64 КБ JS (gzip), шрифты с предзагрузкой, CLS < 0.02,
  canvas останавливается, когда уходит за пределы экрана.
- **SEO:** canonical, Open Graph, Twitter Cards, sitemap, разметка JSON-LD (`ProfessionalService` и `FAQPage`).
- Глубокие ссылки вида `/#pricing` открываются сразу на нужной секции.
