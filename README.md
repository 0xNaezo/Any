# Nightloom

Лендинг и портфолио небольшой инженерной студии: тёмная «ночная» эстетика, сдержанная типографика и один
wow-момент — жаккардовый станок на WebGL, который при прокрутке ткёт логотип-призрака нить за нитью.

Весь текст — заглушки, написанные для того, чтобы показать тон. Перед запуском замените его своим
(см. [чек-лист](#перед-запуском)).

## Стек

- [Astro 7](https://astro.build): статический сайт, ноль фреймворков на клиенте
- TypeScript, чистый CSS с дизайн-токенами (`src/styles/global.css`)
- [GSAP](https://gsap.com) (ScrollTrigger, SplitText) и [Lenis](https://lenis.darkroom.engineering) для анимаций и плавной прокрутки
- Станок: собственный фрагментный шейдер на WebGL, без three.js
- Шрифты подключены локально через Fontsource: Cormorant Garamond (заголовки), Onest (текст), JetBrains Mono (подписи). Все с кириллицей

## Запуск

```bash
nvm use          # Node 22, см. .nvmrc
npm install
npm run dev      # http://localhost:4321
npm run build    # статическая сборка в dist/
npm run preview  # посмотреть сборку локально
npm run check    # проверка типов
```

## Как менять контент

**Тексты.** Всё в `src/i18n/en.ts` и `src/i18n/ru.ts`, у обоих файлов одинаковая структура. Поля, помеченные в
`types.ts` как `Html`, понимают `<em>` (курсив золотом) и `<br>`.

**Проекты** (`work.items`). Пока у каждого кейса встроенная SVG-иллюстрация (`art`). Чтобы поставить настоящие
скриншоты, положите файл в `public/work/` и укажите `image: '/work/halcyon.jpg'` (5:4, от 1600 px по ширине). Ссылка на живой продукт — поле `url`.

**Команда** (`team.members`). Без фото показываются инициалы на тканом узоре (у каждого свой: саржа, ёлочка, ромб,
гусиная лапка). Для фото — `photo: '/team/mark.jpg'` (портрет 4:5).

**Клиенты в первом экране.** Список вордмарков — в начале `src/components/Hero.astro`. Замените на настоящие логотипы
(SVG) только тех клиентов, которые разрешили себя показывать.

**Цены, этапы, FAQ, цифры** — в тех же файлах `en.ts` / `ru.ts` (`engagement`, `process`, `faq`, `principles`).

**Статус загрузки** («Берём проекты с ноября») — текст в `nav.availability`, включение в `site.availability.open`.

## Форма заявок

По умолчанию (`formEndpoint: ''`) форма проверяет поля и открывает почтовый клиент посетителя с готовым письмом
на `site.email`. Работает без сервера.

Чтобы заявки приходили напрямую, создайте форму в [Formspree](https://formspree.io) (или любом сервисе, который
принимает JSON POST) и пропишите её адрес в `formEndpoint`. Форма отправляет
`name, email, company, budget, message, page, language` и `_subject`. От спама защищает скрытое поле-ловушка.

## Языки

Английский открывается по адресу `/`, русский — по `/ru/`. Язык по умолчанию задаётся в `src/i18n/index.ts`
(`defaultLocale`). При первом заходе на `/` посетитель с русским браузером попадает на `/ru/`; выбор в переключателе
запоминается.

## Станок

Первый экран и манифест делят один холст. Сначала висят нити основы и расступаются перед курсором; при прокрутке
манифеста станок ткёт полотно снизу вверх, а узор — призрак из сатинового дамаска с шёлковым бликом от «луны» и
от курсора. Когда полотно готово, призрак иногда моргает.

- Темп и главы: `CHAPTERS`, `WEAVE_FROM`, `WEAVE_TO` в `src/scripts/stage.ts`
- Цвета нитей и свет: `src/scripts/loom/shaders.ts`
- Плотность ткани и положение призрака: `resize()` в `src/scripts/loom/index.ts`

Производительность: разрешение снижается само на слабых устройствах, рендер останавливается, когда холст вне
экрана. При `prefers-reduced-motion` показывается статичная готовая ткань, без WebGL или без JavaScript —
тканый SVG-призрак.

## Иконки и превью для соцсетей

`public/favicon.svg`, `favicon.ico`, PNG-иконки и `og.jpg` / `og-ru.jpg` (1200×630, отрисованы с настоящего
станка). Если поменяется логотип или слоган — перегенерируйте их.

## Деплой

Сайт полностью статический: подойдут Vercel, Netlify, Cloudflare Pages, GitHub Pages или любой хостинг.
Команда сборки — `npm run build`, папка — `dist`. Страница `404.html` подхватывается этими хостингами
автоматически, `sitemap.xml` и `robots.txt` собираются вместе с сайтом.

## Перед запуском

- [ ] Заменить все заглушки: кейсы, цифры, отзывы, логотипы клиентов, команду, цены, FAQ. Выдуманные отзывы и чужие
      логотипы подрывают доверие сильнее, чем их отсутствие, а во многих странах ещё и нарушают закон
- [ ] Домен: `site` в `astro.config.mjs` и `url` в `src/site.config.ts`
- [ ] Контакты: почта, Telegram, ссылка на созвон, соцсети
- [ ] Реквизиты компании в `site.legal`; текст политики конфиденциальности (`privacy` в `en.ts` / `ru.ts`) показать
      юристу и обновить, если добавите аналитику
- [ ] Адрес формы (`formEndpoint`) и тестовая заявка
- [ ] OG-картинки и фавиконы, если меняется бренд
- [ ] Прогнать Lighthouse на продакшен-домене
