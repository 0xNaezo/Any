# Nightloom

Лендинг и портфолио студии разработки из четырёх человек. Тёмный пиксельный техно-минимализм, два языка (RU/EN), страницы кейсов, генерация OG-картинок и иконок при сборке.

Стек: [Astro 7](https://astro.build) (статическая сборка, TypeScript), [GSAP](https://gsap.com) (ScrollTrigger, SplitText, ScrambleText), [Lenis](https://lenis.darkroom.engineering) (плавный скролл), шрифты Geist, Geist Mono и Geist Pixel.

> **Перед публикацией:** все тексты, кейсы, отзывы, клиенты, цифры, имена и контакты — заглушки. Замените их на реальные данные: выдуманные отзывы и клиенты подрывают доверие и в ряде стран нарушают закон о рекламе. Подробности в разделе [«Чек-лист перед запуском»](#чек-лист-перед-запуском).

## Быстрый старт

Нужен Node.js 22.12 или новее.

```bash
npm install
npm run dev       # http://localhost:4321, правки подхватываются на лету
npm run build     # статическая сборка в dist/
npm run preview   # локальный просмотр собранного dist/
npm run check     # проверка типов и шаблонов
```

## Где что менять

| Что | Где |
| --- | --- |
| Все тексты сайта на русском и английском: hero, услуги, кейсы, команда, отзывы, цены, FAQ, форма, футер, политика | `src/i18n/ru.ts`, `src/i18n/en.ts` |
| Домен, почта, Telegram, ссылка на запись созвона, соцсети, часовой пояс, адрес формы | `src/config/site.ts` |
| Цвета, шрифты, отступы (дизайн-токены) | `:root` в `src/styles/global.css` |
| Порядок и набор секций лендинга | `src/components/Landing.astro` |
| Пункты меню | `nav.links` в словарях. `id` должен совпадать с `id` секции |
| Призрак-логотип и пиксельные иконки | `src/lib/sprites.ts` (битмапы из `#` и `.`) |

Структура словаря описана в `src/i18n/types.ts`. TypeScript подскажет, если в одном из языков не хватает поля.

### Типографика

Тексты из словарей автоматически проходят через типограф (`src/i18n/typograph.ts`). Он ставит неразрывные пробелы после коротких слов, перед тире и между числом и единицей измерения. Делать это вручную не нужно.

В строках с выделением `*звёздочки*` фрагмент выводится приглушённым цветом. Так устроены заголовок hero и заголовки секций.

### Кейсы

Каждый кейс — элемент `work.items` в словаре. Страница `/work/<slug>/` и OG-картинка для неё создаются автоматически.

- `mockup` задаёт сгенерированную иллюстрацию: `dashboard`, `logistics`, `mobile` или `telegram`.
- Чтобы показать настоящий скриншот, положите файл в `public/work/` (папку `public/` создайте в корне проекта) и укажите путь: `cover: '/work/finora.jpg'`. Рекомендуемое соотношение сторон — 16:10, ширина от 1600 px.
- Метрики вроде `'12 нед.'` или `'600 000 ₽'` можно писать как есть. Число выводится пиксельным шрифтом, а единица — обычным, потому что в Geist Pixel нет кириллицы и знака ₽.

### Команда

Пока у участника нет фото, показывается пиксельный аватар (`avatar: 'lead' | 'design' | 'front' | 'ops'`). Для настоящего фото положите файл в `public/team/` и укажите `photo: '/team/artem.jpg'`. Фото выводится в ч/б и цветнеет при наведении. Нужен квадратный кадр от 640 px.

### Акцентный цвет

Акцент задаётся в `--accent` в `src/styles/global.css`. Цвет текста на акцентном фоне — `--accent-ink`. Для OG-картинок продублируйте цвет в `C.accent` в `src/lib/og.ts`.

## Форма заявки

По умолчанию (`form.endpoint: ''`) форма открывает почтовый клиент посетителя с уже заполненным письмом на `site.email`. Ниже показываются прямые ссылки на почту и Telegram на случай, если почтовый клиент не настроен.

Чтобы заявки приходили без почтового клиента, укажите в `src/config/site.ts` адрес, который принимает JSON. Например, форму [Formspree](https://formspree.io): `endpoint: 'https://formspree.io/f/xxxxxxx'`. Подойдёт и свой API или serverless-функция. Форма отправляет `POST` с `Content-Type: application/json`:

```json
{
  "name": "Анна",
  "contact": "anna@company.com",
  "company": "Company",
  "type": ["Веб-приложение"],
  "budget": "0,5–1,5 млн ₽",
  "message": "…",
  "nda": true,
  "locale": "ru",
  "page": "https://nightloom.dev/",
  "_subject": "Заявка с сайта Nightloom"
}
```

- Любой ответ `2xx` считается успехом.
- При ошибке форма показывает сообщение с прямой ссылкой на почту.
- Ботов отсекает скрытое поле-ловушка `website`: заполненные им заявки не отправляются.

## Языки

Русский — основной язык, страницы на `/`; английский — на `/en/`. Список языков задан в `src/i18n/index.ts`.

Чтобы оставить один язык:

1. Удалите его из `locales` в `src/i18n/index.ts`.
2. Удалите папку `src/pages/en`.
3. Уберите локаль из блока `sitemap({ i18n })` в `astro.config.mjs`.

Переключатель языков спрячется сам, hreflang-ссылки перестроятся автоматически.

## Что генерируется при сборке

- **OG-картинки** 1200×630 для главной и каждого кейса в обоих языках (`/og/<lang>/<slug>.png`). Собираются из той же геометрии ночной сцены, что и hero (`src/lib/og.ts`, `src/pages/og/`).
- **Иконки и манифест:** `favicon.svg`, `favicon.ico`, PNG-иконки, `apple-touch-icon.png`, `site.webmanifest`, `robots.txt` (`src/pages/[icon].ts`).
- **`sitemap-index.xml`** с языковыми альтернативами.
- **Разметка** canonical, hreflang, Open Graph/Twitter и JSON-LD: `ProfessionalService`, `FAQPage` и `CreativeWork` для кейсов.

## Деплой

Сайт полностью статический: после `npm run build` достаточно опубликовать папку `dist/`.

- **Vercel / Netlify / Cloudflare Pages:** подключите репозиторий, команда сборки `npm run build`, папка `dist`.
- **GitHub Pages (сайт проекта):** если сайт открывается по адресу вида `https://user.github.io/repo/`, раскомментируйте `base: '/repo'` в `astro.config.mjs`. Все ссылки и ассеты учитывают `base`.
- **Свой сервер:** любой веб-сервер, отдающий статику. Страницу 404 направьте на `dist/404.html`.

Не забудьте поменять `url` в `src/config/site.ts` на реальный домен: от него строятся canonical, OG-ссылки и sitemap.

## Анимации и производительность

- **Интро первого экрана** работает на чистом CSS: заголовок разбит на строки ещё при сборке, поэтому анимация стартует вместе с первой отрисовкой и не ждёт JavaScript.
- **Анимации ниже первого экрана** подключаются по частям, после интро. Заголовки секций разбиваются на строки (SplitText), только когда подходят к экрану.
- **Шрифты:** нужные наборы предзагружаются для каждого языка (`Base.astro`), поэтому текст верстается один раз. Если добавите символы за пределами латиницы и кириллицы (например, `→` или `★`), проверьте, что они есть в шрифте. Иначе браузер догрузит запасной шрифт и пересчитает вёрстку.
- **Без JavaScript** весь контент виден, просто без анимаций. Если бандл не загрузился за 4 секунды, страница показывает всё сама.
- **`prefers-reduced-motion`** уважается: в этом режиме анимации, плавный скролл и пиксельные переходы между страницами отключаются.
- **Ночная сцена** на canvas ставится на паузу, когда она вне экрана или вкладка скрыта, и ограничена 30 fps.
- **Пасхалки:** призрак следит за курсором, по клику растворяется и собирается заново. Часы в сцене и футере показывают время студии (`site.timezone`).

## Структура

```text
src/
  config/site.ts         контакты, домен, адрес формы
  i18n/                  словари RU/EN, типы, типограф
  layouts/Base.astro     <head>, SEO, шрифты, общий каркас
  components/
    Landing.astro        состав лендинга
    sections/            секции лендинга
    mockups/             сгенерированные иллюстрации кейсов
    ui/                  пиксельные примитивы, заголовки секций, сцена
    CasePage.astro       шаблон страницы кейса
    LegalPage.astro      шаблон политики конфиденциальности
  pages/                 маршруты, OG-картинки, иконки
  scripts/               анимации, шапка, форма, часы, переходы, canvas-сцена
  lib/                   битмапы и спрайты, геометрия сцены, генерация OG и иконок
  styles/global.css      токены, типографика, общие стили
```

## Чек-лист перед запуском

- [ ] Тексты, кейсы, цифры и метрики в `src/i18n/ru.ts` и `en.ts` заменены на реальные.
- [ ] Отзывы — настоящие и опубликованы с согласия авторов. Клиенты в ленте логотипов — реальные (или блок `Clients` убран из `Landing.astro`).
- [ ] Команда: имена, роли, опыт, ссылки, фото.
- [ ] `src/config/site.ts`: домен, почта, Telegram, ссылка на созвон, соцсети.
- [ ] Подключён `form.endpoint`, отправлена тестовая заявка.
- [ ] Текст политики конфиденциальности (`privacy` в словарях) подготовлен юристом под вашу юрисдикцию. Для РФ — 152-ФЗ.
- [ ] Если подключаете аналитику (Plausible, Umami, Яндекс Метрика), упомяните её в политике.
- [ ] После сборки проверены OG-картинки (`dist/og/`). Превью ссылки — например, в Telegram или через opengraph.xyz.
